SCS User Guide

This guide explains the normal Staff Claim System workflow: staff submit expense items and manage pending claims, while managers review, approve, reject and report on submitted claims.

Training Sequence

Use SCS in this order

Staff and managers use different screens, but both work on the same claim records and item-level statuses.
Staff LoginSubmit Expense ClaimReview / Edit Pending ClaimsUnderstand Claim StatusManager Approval / RejectionFilter, Print and Export
Important: Each expense item has its own status. A single submitted claim can therefore contain a mix of Pending, Approved and Rejected items.
01 · Staff Login

Sign in with your assigned SCS account

The staff page is used to submit new claims and review your own claim history.

Staff access

Enter the assigned email and password. After successful login, SCS opens the staff claim dashboard and shows the logged-in email.

Two staff tabs

Use Submit New Claim for new expenses and My Claim History to review existing claims, statuses and editable pending items.

Tip: If login is rejected, check that the email matches the assigned account exactly before trying again.
02 · Submit New Claim

Enter each expense as a separate item

One claim can contain several expense items. SCS currently allows up to 10 items in one submission.

4. Enter AmountEnter the expense amount in RM.

5. Attach ReceiptOptional image/PDF under 500KB.
→
6. Submit ClaimAll submitted items start as Pending.

Add more items

Use + Add Item to include more expenses in the same claim. Additional rows can be removed before submission. The maximum is 10 items.

Receipt attachment

Receipt attachment is optional. SCS accepts image or PDF files and blocks files at 500KB or larger. Use Clear File if the wrong receipt was selected.

Before submitting: Check Category, Vendor, Description and Amount carefully. These fields become the manager's review information.
03 · My Claim History

Pending items can still be corrected

Staff can review previous submissions and make limited corrections while an item remains Pending.

Edit Pending Item

Pending items can be edited for Vendor, Description and Amount. Saving the change recalculates the claim total.

Delete Pending Item

A pending item can be deleted from the claim. Use this when an expense was entered by mistake and should not be reviewed.

Delete Entire Claim

The whole claim can be deleted only while every item in that claim is still Pending.

Approved or Rejected items are locked. Once a manager has decided an item, staff can no longer edit or delete that item from Claim History.
04 · Claim Status

Understand what each status means

Status is stored per expense item, not only at the overall claim level.
StatusMeaningStaff ActionManager Action
PendingSubmitted and waiting for manager review.May edit or delete while still Pending.Approve or Reject.
ApprovedManager accepted the expense item.Read-only / locked.Final in the current workflow.
RejectedManager rejected the expense item.Read-only / locked; review rejection remark.Final in the current workflow.
Mixed-status claims are normal. For example, one submitted claim may contain two Approved items, one Pending item and one Rejected item.
05 · Manager Review

Review each expense item before deciding

The Manager Dashboard lists submitted claims and lets managers approve or reject individual items.
1. Manager LoginSign in with an account that has the manager role.
→
2. Review Staff & DateConfirm who submitted the claim and when.
→
3. Check ExpenseReview category, vendor, description, amount and receipt.
→
4. Approve or RejectMake the decision item by item.
→
5. Rejection RemarkEnter a reason when rejecting an item.

Approve

Approve when the expense is accepted. Approved items become locked and are counted under Approved (Claimed) in the manager summary.

Reject

Reject when the expense should not be accepted. SCS prompts for a rejection reason/remark, which is shown back to the staff member.

Review carefully before clicking. In the current SCS workflow, Approved and Rejected items are treated as locked/final items.
06 · Manager Reporting

Filter and summarize claim activity

The Manager Dashboard includes staff, date and grouping controls plus summary totals and export tools.

Filter Staff

View all staff or select a specific staff email to narrow the report.

Date Period

Use Start Date and End Date to restrict claims to the required reporting period.

Group View

Use Standard Claims List, View By Category or View By Staff depending on the reporting need.

Summary Metrics

SCS totals Total Claims, Approved (Claimed), Pending (Unclaimed) and Rejected amounts for the current filtered result.

Output

Use Print / Save PDF for a printable report, or Export to Excel to download the filtered claim data as a CSV-compatible file.

07 · Daily Rules

Keep claims clean and easy to review

Good claim quality makes manager review faster and reporting more reliable.
One expense item, one clear line. Use a clear Vendor and Description instead of combining unrelated expenses.
Choose the correct category. Category is used in manager reporting and breakdowns.
Check the amount before submission. Pending items can be corrected, but approved/rejected items are locked.
Attach a readable receipt when available. Keep the file below the SCS 500KB attachment limit.
Managers should reject with a useful reason. The rejection remark is shown to the staff member in Claim History.
